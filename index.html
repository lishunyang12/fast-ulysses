fast-ulysses wheel index

PEP 503 indexes of the fast-ulysses release wheels. Pick by the CUDA your torch was built against (python -c "import torch; print(torch.version.cuda)"); the torch pin inside each wheel then selects the build for the torch you have. 

pip install fast-ulysses --index-url https://triple-mu.github.io/fast-ulysses/whl/cu12/    # torch built against CUDA 12
pip install fast-ulysses --index-url https://triple-mu.github.io/fast-ulysses/whl/cu13/    # torch built against CUDA 13

--index-url and nothing else. pip merges every index it is given and takes the highest version across all of them, and the newest local version here is always the newest torch — so adding --extra-index-url https://pypi.org/simple makes pip install that wheel and upgrade your torch to match it. These indexes carry no torch of their own, which is what leaves pip no choice but to fall back to the wheel pinned to the torch you already have. Install torch first, from wherever you normally do.

If something else in the environment must come from PyPI anyway, use a per-row index below — only one row is in it, so nothing else can be selected — or write the version out in full: pip install "fast-ulysses==0.2.0+torch213cu130" resolves to exactly one file, under pip and under uv alike. That has to be your row's tag, not this one: any other row pins a torch you do not have, and in a command that can reach PyPI pip satisfies that pin by moving your torch, not by failing.
