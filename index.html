fast-ulysses wheel index

PEP 503 indexes of the fast-ulysses release wheels, published by the index job in .github/workflows/release.yml. Nothing is published here yet: the first release to run that job populates this page with one index per (torch, CUDA) row.

Until then, take a wheel from the releases page, or run fast-ulysses wheel-url in the environment you are installing into, which prints the exact version to ask for. Installation: docs/install.md.

0.1.0 is deliberately absent. Its wheels depend on nvidia-nvshmem-cu13, which these indexes do not carry, so an --index-url install of it could not resolve.
